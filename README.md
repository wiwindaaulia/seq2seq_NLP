# seq2seq_NLP

> Proyek pemrosesan bahasa alami (NLP) berbasis arsitektur *Sequence-to-Sequence* (Seq2Seq) untuk pemodelan dan translasi teks.

## 📌 Tentang Proyek
Proyek ini mengimplementasikan arsitektur Encoder-Decoder (Seq2Seq) untuk menyelesaikan tugas pemrosesan teks. Repositori ini berisi eksperimen pelatihan model, pemrosesan data, serta evaluasi hasil menggunakan Python dan Jupyter Notebook.

## 🚀 Fitur Utama
* **Data Preprocessing:** Pembersihan teks, tokenisasi, dan konversi urutan teks untuk pelatihan model.
* **Model Architecture:** Penerapan arsitektur Seq2Seq dengan komponen *Recurrent Neural Network* (RNN/LSTM/GRU).
* **Training & Experimentation:** Eksperimen pelatihan model yang dicatat melalui Jupyter Notebook.

## 🛠️ Teknologi yang Digunakan
* **Python**
* **TensorFlow / Keras / PyTorch**
* **Google Colab**
* **NumPy & Pandas**
